- article:
  - heading "使い方" [level=1]
  - status: このアプリは、作成した相関図をこの端末のブラウザ内にのみ保存します。サーバーへ送信されることはありません。
  - heading "はじめかた" [level=2]
  - paragraph: 画面上部の「チュートリアル」から、5章のうち好きな章を選んで練習できます。途中で終了して通常使用に戻れます。同じ章を選ぶと続きから再開できます。
  - paragraph: 「新しい相関図」で相関図を作り、基準となる人物（本人）を追加します。以降は、選択中の人物を基準に「配偶者を追加」「子を追加」などから続柄を選ぶと、人物と関係線が自動で描かれます。
  - paragraph: 続柄や性別の名称・線種・色は、設定画面から変更できます。使用頻度の低い続柄は既定で非表示になっているため、必要に応じて「選択肢に表示する」を有効にしてください。
  - heading "保存方法の選び分け" [level=2]
  - list:
    - strong: この端末に保存する
    - text: — 自分専用の端末向けです。次に開いたときも続きから作業できます。
    - strong: 今回だけ使う
    - text: — 共有の端末向けです。端末には一切保存されません。タブを閉じるか再読み込みすると作成した内容は消えるため、必要な内容はその都度書き出してください。
  - paragraph: 画面上部の「データ管理」からいつでも切り替えられます。
  - heading "バックアップと復元" [level=2]
  - paragraph: データはこの端末のブラウザ内にのみあります。端末の故障やブラウザのデータ削除で失われるため、定期的な書き出しをおすすめします。前回の書き出しから7日以上が経過すると、一覧画面でお知らせします。
  - list:
    - listitem: 書き出しは画面上部の「バックアップ」から行います。JSONファイルとして保存されます。
    - listitem: 読み込みは画面上部の「ファイル読み込み」から行います。「追加する」では現在の編集画面を保ったままデータを加え、「置き換える」では今あるデータをすべて置換して相関図一覧へ移動します。
    - listitem: パスフレーズを設定すると、書き出したファイルを暗号化できます。パスフレーズを忘れると復元できません。
    - listitem: 別の端末で使う場合は、ファイルを移してから読み込んでください。自動的な同期は行いません。
  - heading "ヘッダーからできること" [level=2]
  - list:
    - listitem: 「ヘルプ」では、このページをいつでも同じ画面で開けます。
    - listitem: 「ファイル読み込み」では、通常または暗号化済みのバックアップを復元できます。
    - listitem: 「コンタクト」は、Kakeizu Studioを選択した共通お問い合わせページを新しいタブで開きます。
  - heading "共有の端末で使い終えたら" [level=2]
  - paragraph: このアプリにはログアウトがありません。共有の端末では、次のいずれかを行ってください。
  - list:
    - listitem: 最初に「今回だけ使う」を選んでおく（もっとも確実です）
    - listitem: 「データ管理」の「この端末のデータをすべて削除」を実行する（必要なら削除前に書き出せます）
    - listitem: ブラウザのゲストモードやプライベートウィンドウで利用する
  - paragraph: 書き出した画像やJSONファイルが端末に残っていないかも、あわせてご確認ください。
  - heading "アプリとしてインストールする" [level=2]
  - paragraph: EdgeやChromeのアドレスバーにあるインストールのアイコン、またはメニューの「アプリとしてインストール」を選ぶと、スタートメニューに登録され、独立したウィンドウで起動できます。インストール後はインターネットに接続していなくても利用できます。
  - paragraph: 新しいバージョンを取得すると自動的に更新され、画面が再読み込みされる場合があります。一時利用中の内容は再読み込みで失われるため、こまめにJSONバックアップを書き出してください。更新のお知らせが表示された場合は、必要な内容を書き出してから「更新する」を押してください。
  - heading "データが消える条件" [level=2]
  - list:
    - listitem: ブラウザの「Cookieとサイトデータを削除」を実行したとき
    - listitem: 「今回だけ使う」でタブを閉じた、または再読み込みしたとき
    - listitem: 「この端末のデータをすべて削除」を実行したとき
    - listitem: 端末が故障した、またはブラウザを変更したとき
  - paragraph: いずれの場合も、書き出したJSONファイルがあれば復元できます。
  - heading "第三者の情報を入力する場合" [level=2]
  - paragraph: 支援対象者やご依頼者など、本人以外の情報を入力する場合、その取得と利用が本人の同意、利用目的の範囲、所属機関の定めに照らして適法であることをご確認ください。書き出したファイルの保管方法も、所属機関の定めに従ってください。
  - heading "外枠とファイル書き出し" [level=2]
  - paragraph: エディター上部の「外枠」から、画面の点線の表示と書き出す画像の横幅・縦幅を設定できます。初期状態では点線は非表示ですが、人物の配置制限と書き出し画像の点線は残ります。
  - paragraph: 横幅・縦幅は図ごとに保存されます。外枠を小さくすると、はみ出す人物を内側へ移動するため、人物が重なる場合があります。
  - paragraph: 「全体プレビュー」で配置を確認できます。保存するときは「編集に戻る」で画面を閉じ、「ファイル書き出し」から形式を選んでください。
  - paragraph: 「ファイル書き出し」では、透過PNG・白背景PNG・JPEG・1ページのPDFを選べます。PDFは図を画像として配置するため、文字の選択や検索はできません。対応ブラウザでは保存場所を選べます。非対応ブラウザでは通常のダウンロードになります。
