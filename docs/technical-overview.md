# Kakeizu Studio 技術仕様書（導入検討用）

所属機関での利用可否をご判断いただくための資料です。ソフトウェアの構成と、情報がどこに保存され、どこへ送信されるかを記載しています。

最終更新: 2026-09-16 ／ 対象バージョン: 3.0.0

## 1. 概要

| 項目           | 内容                                                                 |
| -------------- | -------------------------------------------------------------------- |
| 名称           | Kakeizu Studio                                                       |
| 用途           | 家族相関図（ジェノグラム）の作成                                     |
| 形態           | Webアプリケーション（ブラウザで動作）／PWAとして端末にインストール可 |
| 費用           | 無償                                                                 |
| アカウント登録 | 不要（ログイン機能なし）                                             |
| 動作要件       | Edge、Chrome、Firefox、Safari の最新版                               |

## 2. データの保存場所

**利用者が入力した内容は、利用者の端末内にのみ保存されます。提供者のサーバーには保存されません。**

| 保存先                  | 保存される内容                             | 消去方法                                                             |
| ----------------------- | ------------------------------------------ | -------------------------------------------------------------------- |
| ブラウザの IndexedDB    | 相関図（氏名・続柄・メモ・配置）、表示設定 | アプリの「この端末のデータをすべて削除」／ブラウザのサイトデータ削除 |
| ブラウザの localStorage | 保存方法の選択結果のみ                     | 同上                                                                 |
| 提供者のサーバー        | **なし**                                   | —                                                                    |

「今回だけ使う」モードを選択した場合、端末への書き込みは一切行われず、メモリ上にのみ保持されます。タブを閉じるか再読み込みした時点で失われます。共有端末での利用を想定した機能です。

## 3. 通信先

アプリの利用中、**自ドメイン以外への通信は発生しません**。

| 通信先                       | 内容                              | 発生時点                     |
| ---------------------------- | --------------------------------- | ---------------------------- |
| 配信元ドメイン（自ドメイン） | HTML・JavaScript・CSS・画像の取得 | 初回アクセス時、および更新時 |
| その他の外部サービス         | **なし**                          | —                            |

具体的に、次のものを一切使用していません。

- アクセス解析ツール（Google Analytics 等）
- 広告配信、トラッキング用のタグ
- 外部CDN、外部フォント（Google Fonts 等）
- エラー監視、ログ収集サービス
- 外部API

インストール後（PWA）は、起動時に配信元への通信も発生せず、完全にオフラインで動作します。

**確認方法**: ブラウザの開発者ツール（F12）→ Network タブを開いた状態でアプリを操作すると、自ドメイン以外への通信が記録されないことを確認できます。

## 4. 情報の外部提供

| 項目                   | 有無                         |
| ---------------------- | ---------------------------- |
| 第三者への提供         | なし                         |
| 外部への業務委託       | なし                         |
| 国外への移転           | なし                         |
| 提供者による内容の閲覧 | 不可能（保持していないため） |

配信基盤（Cloudflare Pages）において、通信の成立に必要な範囲でアクセスログが記録されることがあります。これは静的ファイルの配信に伴うもので、アプリに入力した内容は含まれません。

## 5. 書き出したファイルの取り扱い

利用者の操作により、次のファイルを端末へ保存できます。いずれもアプリの管理外に置かれるため、保管は利用者側の管理となります。

| 形式 | 内容                             | 保護                                     |
| ---- | -------------------------------- | ---------------------------------------- |
| PNG  | 相関図の画像（氏名・メモを含む） | なし。書き出し時に画面上で注意を表示     |
| JSON | 全データのバックアップ           | 任意のパスフレーズによる暗号化を選択可能 |

JSONの暗号化方式: AES-GCM 256bit、鍵導出は PBKDF2-SHA256（反復 600,000 回）、salt と IV は書き出しごとにランダム生成。パスフレーズを失った場合、復元はできません。

## 6. セキュリティ対策

| 対策                     | 内容                                                           |
| ------------------------ | -------------------------------------------------------------- |
| 通信の暗号化             | HTTPS を強制（HSTS 有効）                                      |
| Content-Security-Policy  | 外部スクリプト・外部接続を禁止。インラインスクリプトを持たない |
| クリックジャッキング対策 | `X-Frame-Options: DENY`、`frame-ancestors 'none'`              |
| MIMEタイプ推測の抑止     | `X-Content-Type-Options: nosniff`                              |
| リファラの抑止           | `Referrer-Policy: no-referrer`                                 |
| 端末機能へのアクセス     | カメラ・マイク・位置情報をいずれも無効化                       |

上記の設定が緩められていないことは、自動テストによって継続的に検査しています。

## 7. 構成

| 層           | 使用技術                                         |
| ------------ | ------------------------------------------------ |
| 画面         | React 19 / TypeScript                            |
| 図の描画     | React Flow                                       |
| 保存         | ブラウザの IndexedDB                             |
| 配信         | 静的ファイルのみ（アプリケーションサーバーなし） |
| サーバー処理 | **なし**                                         |

主要な依存ライブラリ（いずれも配信ファイルに同梱され、実行時に外部から取得されることはありません）:

- `react` / `react-dom` — 画面描画
- `react-router-dom` — 画面遷移
- `@tanstack/react-query` — データ取得の状態管理
- `@xyflow/react` — 相関図の描画
- `idb-keyval` — IndexedDB への読み書き
- `html-to-image` — PNG 書き出し
- `lucide-react` — アイコン

## 8. 利用上の留意点

- **データの保全は利用者側の責任です。** 端末の故障やブラウザのデータ削除で失われます。JSON書き出しによるバックアップ機能を備えていますが、実行は利用者の操作によります
- **共有端末では消去操作が必要です。** ログアウトの概念がないため、「今回だけ使う」モードの選択、または利用後の全データ削除をご案内しています
- **第三者の情報を入力する場合**、その取得・利用の適法性（本人同意、利用目的の範囲、貴機関の規程との整合）のご確認は、利用者側でお願いしています
- 本アプリは作図の補助を目的としており、専門的判断を提供するものではありません
