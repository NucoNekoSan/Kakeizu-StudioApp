# 引き継ぎ後のブラウザ検証（2026-10-15）

## 環境と範囲

Windows の Brave（Chromium 系）で、`npm run build` の成果物を Vite preview の `http://127.0.0.1:4187` から配信して確認した。本番や既存の利用者データには触れていない。すべて架空の検証用データを使用した。

検証中だけビルド成果物に外部スクリプトの観測パネルを追加し、IndexedDB の open 呼び出し回数・データベース一覧、CSP 違反イベント、Service Worker の状態を画面へ表示した。このスクリプトはソース・公開成果物には含めない。

出力テストでは、タイトルに `<img src=x onerror=alert(1)>` と引用符、メモに同じ文字列・`<script>alert(1)</script>`・改行・RTL 制御文字を含めた。保存先選択ダイアログの OS 操作を避けるため、検証用スクリプトで File System Access API を無い状態にし、アプリ既定のダウンロード方式を通した。ブラウザのダウンロード観測はタイムアウトし、内部のダウンロード履歴ページへのアクセスも操作ポリシーにより不可だったため、端末へのファイル保存完了は合格扱いにしていない。

## 修正・自動検証

- PR #1 の目的を現在の保存処理に合わせて実装。IndexedDB の初期化だけでなく、遅延して行う利用可否確認の失敗もメモリ退避として検知する。
- 一覧・管理画面だけでなくエディターにもバナーを表示し、バナーの高さに合わせて編集領域を伸縮させる。警告ではタブを閉じる・再読み込みによる消失と JSON バックアップを案内する。相関図がある場合の beforeunload と、アンマウント時の解除をテストした。
- ヘルプの「更新するを押した時だけ切り替わる」という古い説明を、自動更新・再読み込みの実動作に合わせて修正した。
- Vitest 395 件、ESLint、TypeScript、production build が成功。

## 検証の限界

- Firefox・Safari、OS の保存先選択ダイアログ、旧 Service Worker が waiting のまま残る移行パターンは未検証。
- 一時利用・メモリ退避の相関図は再読み込みで失われる。beforeunload の確認ダイアログはブラウザの制約を受け、すべての終了方法を防ぐ保証はない。
- 本番のヘッダ・TLS の確認結果は [診断報告書 F9](pentest-report-2026-10.md#f9-tls-10--11-を受け付けている) に記録。
